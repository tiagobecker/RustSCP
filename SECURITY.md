# Security Policy

The RustSCP team takes security and user privacy with utmost seriousness, especially because RustSCP handles sensitive credentials, private SSH keys, and cloud tokens.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in RustSCP:

1. **DO NOT** open a public issue on GitHub.
2. Please report the issue privately by emailing the maintainer or opening a **GitHub Private Security Advisory** under the `Security` tab of this repository.
3. Include detailed steps to reproduce the vulnerability, proof of concept (if applicable), and impact assessment.

We commit to:
- Acknowledging your report within 48 hours.
- Providing a coordinated timeline for resolution and release.
- Giving public credit to the reporter upon patch release (unless requested to remain anonymous).
